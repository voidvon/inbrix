# 价格汇总表 CSV 匹配规则

以《主要项目_价格汇总表.csv》为例(~/Downloads/,UTF-8-SIG,列头固定)。

## 列结构

`型号, 口径, 价格, 价格年份, 建议价格, 物料代码, 分类, 必要说明, 库存状态, 参考编号, 英文描述, 材质, 规格, 数量, TIS项目, 来源文件, 文档名, 表格标题, 表格序号`

- **型号列是主键**,承载阀体材质/连接方式/压力等级/配置等区分信息,必须逐 token 解析,不能只按前缀匹配。
- 价格是 2024 年、含 13% 增值税的数字(千分位逗号);**建议价格 = 价格 × 1.1,不落库**。
- 库存状态(有/无库存)、物料代码按用户约定**不写入价格记录**(纯金额);如需追溯查 CSV 原文。

## 型号列解析(按品牌积累词典)

斯派沙克已见过的模式:

| 型号片段 | 含义 | 拆到哪个维度 |
| --- | --- | --- |
| `25P SG/CI/CS Blue` | 球墨铸铁/铸铁/铸钢 + 蓝色弹簧 | body_material、控制弹簧 |
| `DP27 BSP` / `DP27 PN25/16` / `DP27LC` | 螺纹/法兰等级/低排量 | connection、size(DN15LC) |
| `KE73 Kvs 4.0 PN16` | 裸阀按 Kv 定价 | kv_range、connection |
| `KE73 PEEK + PN9126E + SP7` | 成套(阀+执行器+定位器) | 只记裸价,成套价写报价说明 |
| `M10S2 RB` / `M10Si2 RB` | 碳钢/不锈钢,缩径 | body_material(i=不锈钢) |
| `DCV3 METAL/EPDM/VITON` | 阀座材质三档 | seal |
| `BSA2T PN16/PN25`、`BSA2-BD` | 节流型+PN / 平衡阀芯版 | connection、structure |
| `MFP14S INC./EXC. CHK VLVS` | 含/不含止回阀 | structure |
| `SV615 AS` | 螺纹 BSP 标准配置 | 口径写成 进口x出口 |

## 口径列换算

英寸螺纹与 DN 法兰是**两套不同变体**(同 DN 不同价):

| 英寸 | DN | 英寸 | DN |
| --- | --- | --- | --- |
| 1/4" | DN8 | 1 1/4" | DN32 |
| 3/8" | DN10 | 1 1/2" | DN40 |
| 1/2" | DN15 | 2" | DN50 |
| 3/4" | DN20 | 2 1/2" | DN65 |
| 1" | DN25 | | |

- 安全阀口径是 `进口 x 出口`(如 `1/2" x 3/4"` → DN15 变体,size 写 `DN15 (1/2" x 3/4")`)。
- 泵类有 `DN80 x DN50` 与 `3" x 2"`(同一尺寸的 ASME/NPT 连接版,connection 区分)。
- 变体 size 标签统一 `DNxx (英寸)` 格式;纯 DN 法兰只写 DNxx。

## 易错点(实际踩过)

1. **重名型号陷阱**:`SB` 是 HL10 高温切断装置的阀门,**不是** S 系列倒吊桶疏水阀;`BCV43` 不是 `BCV20`;`TD42S2` 不是 `TD42L/H`;`KE71/KE43` 是别材质阀体。匹配前核对 `文档名/表格标题` 列确认产品线。
2. **同一产品多张价格表冲突**(如 M10S2 有两份表,尺寸-价格错一位):优先取与配套型号(如 M10Si2)同文档的表;不一致处在总结里报告用户。
3. **CSV 覆盖面 ≠ 官方口径全系列**(如 FT14 价格表只有 1¼"–2",官方系列 DN15–25):无价的变体保留不挂价,报价说明写"另询"。
4. **备件/导阀行不是主阀配置**(型号含"备件/Kit/导阀/总成"或文档名含"备件"):不做成变体,价格写进报价说明。
5. 表头行(有型号无口径无价格)跳过;`-` 价格跳过。

## 匹配后落库

- 每个匹配行 → 一个变体 + `{"amount", "currency": "CNY"}`;`price_year` 维度填 CSV `价格年份` 列(当前整表 2024)。
- 建档前先跑只读 dump(参考 `tmp/spirax_price_dump.py` 的做法:按型号正则分组打印 型号|口径|价格|文档|表格),人工过目后再写更新脚本。
